# Issues and contributions

These are example clients for the [Diamond API](https://diamondapi.live/diamond-api-integration). Issues and pull requests are welcome.

**Never paste an API key** into an issue, a pull request or a log excerpt. If you shared one by mistake, ask us for a new key at https://diamondapi.live/telegram and we will revoke the old one.

When something does not work, please include:

- the example and language you ran, and your runtime version (`node -v`, `python --version`, `php -v`, `curl --version`);
- the HTTP status and the error `code` you got;
- the `X-Request-Id` response header, which lets us find the request.

Questions about your account, keys, IP allowlist or plan go to https://diamondapi.live/telegram, not to issues.

Pull requests: keep each example a single readable file, keep Node free of dependencies and Python to `requests`, and follow the README for behaviour. A new language is welcome if it covers the same four examples.
